## Stack

단일 페이지 정적 사이트 — 빌드 과정 없음.
- `index.html` — 전체 페이지 (단일 파일)
- `styles.css` — 스타일 전체
- 외부 라이브러리: GSAP + ScrollTrigger (cdnjs), Lenis smooth scroll (jsDelivr)
- 폰트: Fraunces · Ma Shan Zheng · Noto Sans/Serif KR · JetBrains Mono (Google Fonts)
